# AGYZ - Multi-Agent Workspace Orchestrator

منصة مركزية متطورة لإدارة وتوليد جلسات وكلاء الذكاء الاصطناعي (Google Antigravity - AGY) لفِرق العمل والمطورين، مع التحكم الكامل في مسارات الساندبوكس والصلاحيات.

## المميزات الرئيسية (Key Features)

1. **لوحة تحكم المدير (Admin Orchestrator):**
   - توليد جلسات مخصصة لكل عضو في الفريق برمز وصول خاص (Token).
   - تحديد مجلد الساندبوكس لكل جلسة بدقة (مثل `/root/wino/ferme` أو `/root/test`).
   - التحكم في الصلاحيات لكل جلسة:
     - تفعيل أو تعطيل الساندبوكس (`--sandbox`).
     - الموافقة التلقائية على تنفيذ الأدوات (`--dangerously-skip-permissions`).
     - متابعة سياق المحادثة (`--continue`).
     - تحديد الواجهات المتاحة (الدردشة فقط، الطرفية فقط، كلاهما).
   - إيقاف مؤقت، تنشيط، أو إغلاق وحذف أي جلسة في أي وقت.

2. **بيئة عمل الوكيل للعضو (Agent Workspace Console):**
   - دخول مباشر وآمن عبر رابط الجلسة المشفر بالتوكن.
   - وضع الدردشة الذكية (AI Chat) بأسلوب Gemini و ChatGPT مع دعم Markdown والأكواد.
   - طرفية تفاعلية حية (Live Terminal) مقيدة بمسار الساندبوكس المسموح به مع دعم كامل للغة العربية.

## التشغيل (Run)

```bash
npm install
npm start
```
افتراضياً يستمع التطبيق على المنفذ `3333` ويمكن تغييره عبر متغير البيئة `PORT`.
