استرجاع وحفظ الذاكرة المعرفية للوكيل وربط سياق النماذج عبر بروتوكول MCP

خادم الذاكرة متصل ومربوط بالوكيل
اقتراحات سريعة:
سيتم تخزين الذاكرة في خادم MemoryZ السحابي وتوليد متجهات التضمين دلالياً، لتكون متاحة للوكيل عبر بروتوكول MCP تلقائياً.
اسم خادم MCP:
memoryz
بروتوكول الاتصال:
Model Context Protocol (Stdio / SSE)
نقطة النهاية السحابية (Endpoint):
https://memoryz.wino.deno.net/mcp
محرك التضمينات الدلالية:
Google Gemini 768-dim Embeddings
الأدوات المتاحة للوكيل:
recall, store, reflect, context
أمر تسجيل خادم MCP في الوكيل (مسجل تلقائياً):
agy mcp add memoryz npx -y memoryz mcp

ربط الجلسة مع Claude و ChatGPT (Remote MCP) MCP Active

تحكم بالوكيل ومساحة المشروع مباشرة من داخل محادثات ChatGPT أو Claude برابط موحد

ساندبوكس مقيّد ونشط
1. رابط Remote MCP لـ Claude و Cursor و Windsurf: Streamable HTTP / SSE

في تطبيق Claude Desktop أو Claude Web أو Cursor: أضف خادم MCP واختر النوع URL وضع هذا الرابط مباشرة.

2. رابط OpenAPI 3.1 Schema لـ ChatGPT Actions (Custom GPTs): OpenAPI 3.1.0

في ChatGPT (Create a GPT): اذهب إلى Configure → Actions → Import from URL وضع هذا الرابط لاستيراد الأدوات فوراً!

الأدوات المتاحة لـ Claude و ChatGPT للتحكم في مشروعك:
  • ask_agent: إرسال مهام برمجية وأوامر للوكيل لينفذها ويعدل الملفات داخل المشروع.
  • list_workspace_files: تصفح هيكلية المجلدات والملفات.
  • read_workspace_file: قراءة محتوى أي كود أو ملف.
  • write_workspace_file: إنشاء أو تعديل ملفات الكود مباشرة.
  • run_shell_command: تشغيل أوامر تيرمنال داخل مجلد المشروع.
