المميزات الجوهرية لمنصة VibzCode

صُممت المنصة لتلبي احتياجات الفرق البرمجية وتطوير الوكلاء المستقلين بأعلى درجات العزل والأمان.

عزل كامل بالساندبوكس (Per-Session Sandbox)

كل عضو وكل مشروع يمتلك مساراً معزولاً ورمز وصول خاص (Token)، ولا يمكن لأي وكيل تجاوز حدود المجلد المحدد له ما لم يمنحه المدير صلاحية صريحة.

أمان بيئات العمل Strict Path Check

خادم Remote MCP برابط موحد

ربط فوري عبر البروتوكول الرسمي @modelcontextprotocol/sdk يتيح تشغيل الجلسة داخل Claude Desktop و Cursor و ChatGPT Actions برابط واحد موحد ومحمي.

دعم SSE و JSON-RPC 2.0 Standard MCP

تفرع الجلسات اللانهائي (Session Forking)

إمكانية نسخ أي جلسة أو تفريعها عند أي نقطة زمنية لتجربة فكرة برمجية جديدة دون التأثير على المسار الأصلي، مع عرض هرمي ذكي يوضح شجرة العائلة لكل فرع.

إدارة فروع المهام Hierarchical Tree

معاينة تفاعلية وتحميل بالضغط المطول

عند إنشاء الوكيل لأي ملف وسائط (صور، فيديو MP4، صوت، PDF، أكواد)، يتم تحويل الروابط فوراً لشرائح تفاعلية تُفتح بنافذة منبثقة، وتدعم التنزيل الفوري عند الضغط المطول.

تفاعل وسائط متقدم Long-Press Download

طرفية تفاعلية حية (Live Terminal BiDi)

جلسة Bash حقيقية في المتصفح مبنية على node-pty و xterm.js تدعم تشكيل الحروف العربية والنصوص ثنائية الاتجاه، ومحصورة بالساندبوكس.

تيرمنال ويب حقيقي WebSocket PTY

ذاكرة مشتركة مع MemoryZ و Jev AI

ربط الوكلاء مع منصة MemoryZ لاسترجاع القواعد البرمجية والذكريات المشتركة دلالياً (Semantic Search)، وتحليل الأخطاء البرمجية ذاتياً عبر النماذج الذكية.

خيارات التنصيب والتشغيل السريع

سواء أردت تجربة فورية بدون تثبيت، أو تنصيب الأداة عالمياً عبر npm/pnpm، أو استنساخ الكود للمطورين.

الأسرع (Instant)

1. تشغيل فوري عبر NPX

تشغيل مباشر دون تنزيل دائم؛ يقوم بفحص البيئة، وتشغيل المنصة، وفتح لوحة التحكم تلقائياً: 

# تشغيل مباشر وفوري
npx vibzcode

# أو تحديد منفذ مخصص
npx vibzcode --port 3334
يعمل على Linux و macOS و Windows
Global CLI

2. تثبيت عام (NPM / PNPM)

تثبيت الأداة كأمر نظام دائم في جهازك أو خادمك، لتشغيله في أي وقت بكلمة واحدة: 

# عبر npm:
npm install -g vibzcode

# أو عبر pnpm:
pnpm add -g vibzcode

# ثم التشغيل في أي وقت:
vibzcode
حزمة npm معتمدة وخفيفة الوزن
Self-Hosted

3. استنساخ المطورين (Git & PM2)

للسيرفرات الإنتاجية والتطوير المتقدم، مع إدارة العمليات المستمرة عبر PM2: 

git clone https://github.com/Zizwar/vibzcode.git
cd vibzcode && npm install
cp .env.example .env

# تشغيل كخدمة مستمرة:
pm2 start ecosystem.config.cjs
تحكم كامل بملفات الكود والخدمات

خيارات سطر الأوامر (CLI Flags)

-p, --port <num>
تحديد منفذ الخادم (الافتراضي: 3333 أو متغير $PORT)
--status
فحص جاهزية وتكوين مفاتيح الذكاء الاصطناعي دون تشغيل السيرفر
--no-open
تعطيل الفتح التلقائي للمتصفح (مفيد للسيرفرات البعيدة)
--host <ip>
تحديد الـ Host للربط الشبكي (الافتراضي: 0.0.0.0)
💡 ملاحظة: لوحة التحكم تفتح تلقائياً على الرابط http://localhost:3333 أو http://localhost:3334 بحسب المنفذ المحدد.
