ربط Remote MCP مع Claude و ChatGPT Active

تحكم كامل في مساحة العمل الخاصة بالجلسة عبر بروتوكول MCP برابط موحد

جاهز للربط السحابي
1. رابط Remote MCP الموحد (Claude Web / Mobile / Desktop / Cursor): Streamable HTTP + SSE

في تطبيق Claude Desktop أو Claude Web أو Cursor: أضف خادم MCP وضع هذا الرابط برابط واحد مباشر.

2. رابط OpenAPI 3.1 Schema (مخصص لـ ChatGPT Actions / Custom GPTs): OpenAPI 3.1.0

في ChatGPT (Create a GPT): اذهب إلى Configure → Actions → Import from URL وضع هذا الرابط لاستيراد الأدوات فوراً!

كيف يتحكم ChatGPT أو Claude في الكود والمشروع عبر هذه الجلسة؟
  • بمجرد الربط، تظهر لـ ChatGPT/Claude أداة ask_agent لتنفيذ أي أمر برمجي وتعديل الملفات بواسطة Antigravity (agy).
  • تظهر أدوات list_workspace_files و read_workspace_file لتصفح وقراءة ملفات المشروع.
  • يتم تطبيق ساندبوكس الأمان وحصر العمليات داخل المجلد المحدد للجلسة تلقائياً.

خادم الأوركسترا والتحكم المركزي Platform MCP

تحكم كامل بجميع الوكلاء، المحركات (agy, claude, codex, vibe, opencode)، والذاكرة المشتركة MemoryZ

ما الفرق بين هذا الرابط ورابط الجلسات الفردية؟
• رابط الأوركسترا (هنا): يمنح الوكيل (Claude Desktop أو Cursor أو ChatGPT) صلاحية إدارة المنصة بأكملها: إنشاء جلسات، توجيه مهام لأي محرك، تمرير النتائج بين الوكلاء، واسترجاع الذكريات من MemoryZ.
• رابط الجلسة الفردية (في بطاقات الجلسات): مقيد بساندبوكس مشروع واحد فقط لمطور أو وكيل مستقل.
1. رابط خادم الأوركسترا المباشر (Claude Desktop / Cursor / Web): Streamable HTTP + SSE

أضف هذا الرابط في Claude Desktop أو Cursor ليصبح العميل قائد الأوركسترا (Orchestrator).

2. رابط OpenAPI للأوركسترا (Custom GPTs / Open WebUI): OpenAPI 3.1.0

في ChatGPT Custom GPTs أو Open WebUI: أضف Action برابط schema المباشر أعلاه.

الأدوات المتاحة للأوركسترا بمجرد الربط:
agent_dispatch

توجيه مهمة لأي محرك/جلسة في الخلفية مع حقن الذاكرة.

handoff

تمرير ناتج وكيل إلى وكيل آخر تلقائياً في سلسلة عمل.

session_create

إنشاء جلسة وكيل جديدة وتحديد المحرك والمسار.

memory_fetch / recall

جلب الذكريات بالهش الدقيق أو البحث الدلالي في MemoryZ.

task_tree / task_claim

تتبع شجرة المهام الهرمية والقفل الذري لمنع تصادم الوكلاء.

notify

إرسال تنبيهات للمطور عبر Telegram أو Webhook.
